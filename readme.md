## Birthday CLI

Birthday CLI is a command-line tool to manage and track birthdays.

### Features

- Add, list, and remove birthdays
- Search for upcoming birthdays
- Simple and fast CLI interface

### Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/birthday-cli.git
    cd birthday-cli
    ```
2. Download dependencies:
    ```sh
    go mod tidy
    ```
3. Build the application:
    ```sh
    go build main.go
    ```
    This will create a binary named `main` in the root folder.

### Usage

Run the CLI tool:
```sh
./main
```

Use the available commands to manage birthdays. For help:
```sh
./main --help
```
